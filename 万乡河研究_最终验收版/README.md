# 万乡河流域双灾种（洪涝/泥石流）危险性—暴露性—风险研究 · 最终验收版

本目录是万乡河流域洪涝与泥石流双灾种风险研究的**最终数据版本**（版本锁定日期 2026-11-12），与仓库根目录的桂林市泥石流灾害点数据库互补：根目录提供区域性灾害点底数，本目录提供流域尺度的危险性评价、组合危险性分析与承灾体暴露性统计全套成果。

## 1. 研究区与统一评价框架

| 项目 | 参数 |
| --- | --- |
| 研究区 | 广西桂林市全州县万乡河流域（湘江上游支流） |
| 统一评价单元 | 100 m × 100 m 栅格，360 × 277，EPSG:32649（WGS 1984 UTM 49N） |
| 有效评价像元 | 洪涝 69,726（124 个 HAND 缺失像元保持 NoData）；泥石流 69,850 |
| 有效评价面积 | 697.26 km² |
| 危险性模型 | AHP 加权叠加 H = Σ wi × Ri + Jenks 自然断点 5 级（编码 1=低 … 5=高，255=NoData） |
| 组合分析 | ArcGIS Combine 生成 21 种洪涝—泥石流实际组合（Hazard_Combine） |

AHP 权重通过一致性检验（洪涝 CR=0.0112，泥石流 CR=0.0145 < 0.1）；洪涝第一因子为距河距离（w=0.4157），泥石流第一因子为坡度（w=0.2537）。

## 3. 关键成果数字

**组合危险性（21 种组合合计，均已对账）**

| 统计项 | 数值 |
| --- | --- |
| 像元总数 | 69,726 |
| 人口 | 131,518.6 人 |
| 建筑面积 / 建筑要素 | 88,926.9 m² / 76 个（质心口径） |
| 道路 / 桥梁 / 学校要素 / 居民点 | 129.908 km / 8 座 / 8 个 / 5 处 |

**核心空间格局**（组合13 = 洪涝高×泥石流高）：

- 双高组合区 40.60 km²（占 5.8%），承载 9.4% 人口、27.9% 建筑面积、25.0% 道路里程、1/3 居民点、2 处学校要素
- 组合13 为全流域"近河道陡坡带"集合（295 个面片散布各支沟峡谷；实测 34.2% 像元近河道(HAND<50m)且陡坡(>15°)，坡度均值 17.5°）
- 组合11（洪涝高×泥石流较高）人口最多（34,562 人，26.2%，龙水镇宽谷段）；组合17（洪涝高×泥石流中等）建筑面积最大（27,981 m²，才湾镇宽谷段）
- 洪涝高危险 4 个组合合计人口占 62.2%，而面积仅占 18.0%——人口沿河谷走廊集聚
- 8 座桥梁全部位于洪涝较高以上组合，无一在低风险区（河谷线位决定，无避让空间）

**两灾种高危险带地形分异（实测）**：

- 洪涝：HAND 均值随等级 1→5 单调递减（267.8→17.2 m），5 级 90.3% 位于河道 50 m 相对高度带内——沿干支流河道低地呈树枝状条带
- 泥石流：坡度随等级 1→5 单调递增（5.1°→25.1°，5 级 84.3% >15°），HAND 均值单调递增（31→158 m）——沿沟谷两侧陡坡面呈斑块状
- 两条高危险带在支沟峡谷段空间叠置，构成双高区

## 4. 统计口径（引用时必读）

1. **基础分区** = Hazard_Combine（21 种实际组合）；洪涝 124 个 HAND 缺失像元为 NoData，不参与任何统计（对应未评价人口 596.8 人）
2. **人口** = GHS-POP 2020 重采样 100 m 分区求和（像元=人）
3. **建筑面积** = 76 个建筑要素与组合区 Intersect 的实际面积（可跨组合拆分）；**建筑轮廓数** = 质心归属计数；76 个要素对应 75 个唯一 OSM 建筑（OSM way 1450022520 被分为两个要素，分别落入组合 9 与组合 5）
4. **学校**：8 个空间要素对应 7 所学校（全州二中含主校区与高中部 2 个要素），论文表述建议用"学校空间要素数量"
5. **道路/河流长度** = 与组合区 Intersect 拆分后的区内长度（按位置选择的要素全长口径无效）；道路原始 130.767 km → 组合区内 129.908 km（0.619 km 位于洪涝未评价区，约 0.24 km 为转面平面化损耗）
6. **桥梁/学校/居民点** = 点落入组合区计数（Spatial Join JOIN_ONE_TO_ONE/KEEP_ALL/INTERSECT，全部 Join_Count=1，无边界遗漏）
7. **建筑面积口径修正**：旧值 88,934.5 m² 混入 2 个被剔除轮廓的 7.6 m²，严格 76 要素口径为 88,926.9 m²

## 6. 工具链与可复现性

ArcGIS 10.8 arcpy（ZonalStatisticsAsTable / Combine / RasterToPolygon / Intersect / SpatialJoin / CopyRaster）；Jenks 分级 jenkspy；连续指数与分类栅格由 phase4_report.json 记录断点参数。所有统计 CSV 可与 gdb 图层逐一核对。

## 7. 数据说明与免责

DEM 来源于公开 30 m 数据；人口为 GHS-POP 2020 重采样；建筑/学校为 OSM 矢量；居民点/道路/桥梁/岩性为 DLG 成果。成果仅供学习与研究参考，危险性等级为相对分级（AHP+Jenks），不构成工程防灾依据；灾害风险以专业评估为准。

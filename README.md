# 广西桂林泥石流灾害数据

广西壮族自治区桂林市泥石流灾害点空间数据与整理成果。

## 目录结构

```
data/
  guilin/    桂林市泥石流灾害点（34 个点，Shapefile）
  guangxi/   广西全区地质灾害点（15440 条，Shapefile）+ 原始压缩包
output/      整理成果表（Excel）
万乡河研究_最终验收版/   万乡河流域洪涝/泥石流双灾种危险性—暴露性—风险研究
                         最终数据版本（详见该目录下 README.md）
```

## 属性字段

共 35 个字段：灾害体类型、灾害体编号、灾害体名称、野外编号、室内编号、省、市、县、乡镇、地理位置、经度、纬度、X、Y、Z、坡顶/坡底标高、地震烈度、威胁人口、威胁财产、险情等级、灾害等级、隐患点、目前稳定程度、今后变化趋势、治理情况、防治建议、监测建议、毁坏房屋、毁路、毁渠、地下水类型、构造部位、Guid。

**原始数据中没有任何"发生时间/日期"字段**，全广西总表同样没有。

## 关于 output 表中的日期（重要）

Excel 里的"推断发生日期"**不是原始数据**，是按以下方法推得的参考值：

- 先确定该点所在县/乡镇有公开记载的、强度最大的暴雨（山洪）泥石流事件，再以其日期作为该点的推断日期；
- 可靠度"中"：报道中明确出现该点所在乡镇或同村；可靠度"低"：仅能确认该县为受灾县之一；
- 采用的 6 场过程：1994-05-25 灌阳观音阁、1994-06-15 龙胜三门镇、2008-06 阳朔、2017-06-25～07-02 桂林全域、2019-06-09 全州龙水镇（仅参考）、2020-06-07 平乐；
- 34 个点中 25 个属性为"隐患点=1"，属调查登记的隐患点/潜在泥石流沟，本身可能从未发生过泥石流，"发生日期"在原资料中就不存在。

因此该列**只能用于排序和时间维度分析，不可作为灾害点确切发生日期引用**。需要准确日期请查各县《地质灾害调查与区划报告》中的"灾害点统计表（发生时间）"。

## 使用说明

- 用 QGIS / ArcGIS 直接打开 `.shp` 即可，属性表用 `.dbf`。
- 如果克隆后 `data/guangxi/广西.dbf` 显示为几行文本（LFS 指针），需要安装 Git LFS 后执行 `git lfs pull`；或直接解压 `data/guangxi/广西地质灾害数据.zip`。
- 中文文件名在部分系统上需注意编码，建议克隆后不要重命名。

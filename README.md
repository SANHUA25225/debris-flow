# 广西桂林泥石流灾害数据

广西壮族自治区泥石流灾害点空间数据、基础地理辅助数据与整理成果。

## 目录结构

```
data/                        空间数据
  debris flow.shp/.dbf/...   广西全区泥石流灾害点（146 个点）
  debris flow_Guilin.*       桂林市泥石流灾害点（34 个点）
  广西地质灾害数据/            广西全区地质灾害点（15440 条）
  广西地质灾害数据.zip         上一项的原始压缩包（1.76 MB，免 LFS 备用）
  Guilin_clipped/            裁剪到桂林市的水系（HYDL）、道路（LRDL）
  桂林矢量边界/                桂林市行政边界（Guilin）
output/                      表格成果
  桂林市泥石流灾害点清单（34处）.xlsx
  gxjc_图层代码对照表.xlsx
万乡河研究_最终验收版/           万乡河流域洪涝/泥石流双灾种危险性—暴露性—风险研究
                         最终数据版本（详见该目录下 README.md）
```

## 数据说明

### data/debris flow.*（广西全区泥石流点，146 个）

| 文件 | 说明 |
| --- | --- |
| `.shp / .shx` | 点要素几何 |
| `.dbf` | 属性表，35 个字段（与桂林表结构一致，多一个 `灾害体编_1` 重复字段） |
| `.prj / .qmd` | 坐标系定义、QGIS 元数据 |

### data/debris flow_Guilin.*（桂林泥石流点，34 个）

桂林市范围内的泥石流灾害点，35 个字段：灾害体类型、灾害体编号、灾害体名称、野外编号、室内编号、省、市、县、乡镇、地理位置、经度、纬度、X、Y、Z、坡顶/坡底标高、地震烈度、威胁人口、威胁财产、险情等级、灾害等级、隐患点、目前稳定程度、今后变化趋势、治理情况、防治建议、监测建议、毁坏房屋、毁路、毁渠、地下水类型、构造部位、Guid。

### data/广西地质灾害数据/（全区地质灾害点，15440 条）

全区崩塌、滑坡、泥石流等地质灾害点，字段结构与上表一致。`广西.dbf` 为 102.88 MB，超过 GitHub 单文件 100 MB 限制，由 **Git LFS** 管理。

### data/Guilin_clipped/（基础地理辅助数据）

| 文件 | 说明 |
| --- | --- |
| `HYDL_Guilin.*` | 水系线图层（HYDL），已裁剪到桂林市范围 |
| `LRDL_Guilin.*` | 道路线图层（LRDL），已裁剪到桂林市范围 |

图层代码（HYDL / LRDL / AANP / BOUA 等）的含义见 `output/gxjc_图层代码对照表.xlsx`。

### data/桂林矢量边界/

`Guilin.shp` 等为桂林市行政边界。

## output 表格

### 桂林市泥石流灾害点清单（34处）.xlsx

- **Sheet「泥石流点清单」**：34 行逐点清单，41 列 = 属性表全部字段 + 推断发生日期 + 日期可靠度 + 推断依据 + 补充说明 + 同期洪涝情况 + 洪涝规模。
- **Sheet「推断说明与依据」**：数据来源、推断方法、可靠度定义、引用事件出处、同期洪涝说明。

**关于日期（重要）**：原始数据中没有任何"发生时间/日期"字段，全区总表同样没有。表中"推断发生日期"是按"该县/乡镇有公开记载的最强一场暴雨（山洪）泥石流事件"推得的参考值：

- 可靠度"中"：报道中明确出现该点所在乡镇或同村；"低"：仅能确认该县为受灾县之一；
- 采用的 6 场过程：1994-05-25 灌阳观音阁、1994-06-15 龙胜三门镇、2008-06 阳朔、2017-06-25～07-02 桂林全域、2019-06-09 全州龙水镇（仅参考）、2020-06-07 平乐；
- 34 个点中 25 个属性为"隐患点=1"，属调查登记的隐患点/潜在泥石流沟，本身可能从未发生过泥石流。

因此该列**只能用于排序和时间维度分析，不可作为灾害点确切发生日期引用**。需要准确日期请查各县《地质灾害调查与区划报告》中的"灾害点统计表（发生时间）"。

### gxjc_图层代码对照表.xlsx

基础地理信息图层代码对照，含 4 个工作表：图层对照表、GB分类码、字段含义、图幅划分。

## 使用说明

- 用 QGIS / ArcGIS 直接打开 `.shp`（属性表在 `.dbf`）。
- 克隆后若 `data/广西地质灾害数据/广西.dbf` 只有几行文本（LFS 指针），安装 Git LFS 后执行 `git lfs pull`；或直接解压 `data/广西地质灾害数据.zip`。
- 中文文件名在 Git 中以转义形式存储，克隆后不要重命名。
